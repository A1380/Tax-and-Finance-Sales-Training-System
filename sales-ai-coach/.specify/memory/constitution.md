# 项目章程 —— SalesAI Coach

## 1.1 项目名称
**SalesAI Coach —— 财税行业销售AI陪练系统**

## 1.2 项目愿景
为财税服务行业的销售与客服团队，提供一个 **7×24小时、零风险、可量化** 的AI销售陪练平台。通过AI驱动的虚拟客户（Agent）与智能评估体系，帮助销售人员快速提升话术能力、异议处理技巧和客户沟通水平，将传统需要3-6个月的销售实战经验积累周期大幅缩短。

## 1.3 核心原则
1. **场景真实**：所有训练场景必须基于财税行业真实业务场景（财税咨询、短视频获客、客户异议处理等）
2. **反馈即时**：每次对话结束后，系统必须在3秒内给出结构化评分和改进建议
3. **数据安全**：所有对话数据和用户信息必须加密存储，符合财税行业合规要求
4. **可量化评估**：每个训练 session 必须产出可量化的评分报告，支持培训效果追踪
5. **规范驱动开发**：所有开发工作严格遵循 SpecKit 规范流程，先写规范、后写代码

## 1.4 文档语言
所有规范文档、计划文档、任务文档、代码注释和提交信息，**必须使用简体中文（zh-CN）** 。
