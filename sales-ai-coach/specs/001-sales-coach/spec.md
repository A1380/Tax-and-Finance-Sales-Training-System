# 功能规范 —— SalesAI Coach

## 2.1 功能概述
**销售AI陪练系统**是一个基于 **Agentic RAG** 架构的智能销售训练平台。系统通过多智能体协作（AI客户Agent + AI教练Agent + AI评估Agent），为销售人员提供沉浸式的实战演练环境。

## 2.2 用户角色
| 角色 | 描述 |
|------|------|
| 学员（Sales Rep） | 接受培训的销售人员，进行对话演练 |
| 培训管理员（Admin） | 管理训练剧本、查看学员数据、配置系统 |
| 系统（AI Agent） | 自动扮演客户、教练、评估员 |

## 2.3 用户故事（User Stories）

### US-01：作为学员，我希望与AI虚拟客户进行语音/文字对话演练
- **场景**：学员选择训练场景（如"财税咨询冷 call"、"异议处理"），AI扮演虚拟客户进行对话
- **验收标准**：
  - 系统支持至少3种预设训练场景（冷 call、异议处理、需求挖掘）
  - AI客户能够基于场景设定做出合理、拟真的回应
  - 对话支持文字输入（MVP）和语音输入（进阶）
  - 单次对话时长不限，可随时结束

### US-02：作为学员，我希望在每次演练后获得即时、结构化的反馈
- **场景**：对话结束后，系统自动生成包含多维度评分的反馈报告
- **验收标准**：
  - 反馈维度至少包括：开场白质量、需求挖掘能力、异议处理能力、沟通节奏把控、结尾收网能力
  - 每个维度给出具体评分（1-10分）和改进建议
  - 反馈报告以可视化图表呈现，支持导出
  - 反馈生成时间不超过5秒

### US-03：作为学员，我希望查看我的历史训练记录和进步轨迹
- **场景**：学员登录后可以查看所有历史对话记录和评分趋势
- **验收标准**：
  - 系统保存完整的对话历史
  - 提供评分趋势图，展示各维度能力的进步曲线
  - 支持按日期、场景类型筛选历史记录

### US-04：作为培训管理员，我希望能够创建和配置训练剧本
- **场景**：管理员通过自然语言描述创建新的训练场景
- **验收标准**：
  - 支持通过自然语言描述生成训练剧本（AI辅助生成）
  - 剧本配置包括：客户角色设定、场景背景、潜在异议列表、评分标准
  - 支持剧本的启用/停用和版本管理

### US-05：作为培训管理员，我希望查看团队整体的训练数据
- **场景**：管理员查看所有学员的训练完成情况、平均分、能力短板分析
- **验收标准**：
  - 提供团队维度的数据看板
  - 支持按部门、岗位、时间段筛选数据
  - 可导出团队训练报告（Excel/PDF）

## 2.4 功能需求（Functional Requirements）

| ID | 需求描述 | 优先级 |
|----|----------|--------|
| FR-01 | 系统必须支持用户注册、登录和身份认证 | P0 |
| FR-02 | 系统必须提供至少3种预设训练场景（财税冷 call、异议处理、需求挖掘） | P0 |
| FR-03 | 系统必须集成LLM（如GPT-4/Gemini）驱动AI客户进行拟真对话 | P0 |
| FR-04 | 系统必须在每次对话结束后自动生成多维度评分报告 | P0 |
| FR-05 | 系统必须保存完整的对话历史，支持学员回溯查看 | P1 |
| FR-06 | 系统必须支持管理员创建、编辑、管理训练剧本 | P1 |
| FR-07 | 系统必须提供团队维度的训练数据看板 | P2 |
| FR-08 | 系统必须支持对话内容的专业合规校验（财税行业标准） | P1 |
| FR-09 | 系统必须支持RAG知识库检索，确保AI回复内容基于财税专业知识 | P1 |
| FR-10 | 系统必须支持语音输入与语音合成（进阶功能，MVP可先做文字版） | P2 |

## 2.5 非功能需求（Non-Functional Requirements）

| ID | 需求描述 | 指标 |
|----|----------|------|
| NFR-01 | API响应时间 | < 3秒 |
| NFR-02 | 系统可用性 | ≥ 99.5% |
| NFR-03 | 对话数据加密存储 | AES-256 |
| NFR-04 | 支持并发用户数 | ≥ 50人同时训练 |
| NFR-05 | 系统架构可扩展 | 支持后续增加语音、多模态功能 |
