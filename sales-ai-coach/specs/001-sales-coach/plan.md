# 技术方案 —— SalesAI Coach

## 3.1 技术选型

### 后端
| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 编程语言 | Python 3.12+ | AI生态最成熟 |
| Web框架 | FastAPI | 高性能、异步支持、自动API文档 |
| LLM集成 | OpenAI API / 兼容接口 | 支持GPT-4、GLM等 |
| Agent框架 | LangChain / LangGraph | 多智能体协作编排 |
| 向量数据库 | Chroma / Pinecone | RAG知识库检索 |
| 数据库 | PostgreSQL + JSONB | 用户数据、对话记录、评分存储 |

### 前端
| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 框架 | React 18 + Next.js 14 | 成熟的UI框架 |
| 样式 | Tailwind CSS | 快速UI开发 |
| 状态管理 | Zustand / React Context | 轻量级状态管理 |
| API调用 | React Query / Axios | 数据请求与缓存 |

### 基础设施
| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 部署 | Docker + Nginx | 容器化部署 |
| 版本控制 | Git + GitHub | 代码托管 |
| CI/CD | GitHub Actions | 自动化测试与部署 |
