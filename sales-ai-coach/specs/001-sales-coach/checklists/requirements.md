# 质量检查清单 —— SalesAI Coach

## 5.1 需求质量检查

- [ ] CHK001：所有用户故事是否有明确的验收标准？
- [ ] CHK002：功能需求是否都分配了优先级（P0/P1/P2）？
- [ ] CHK003：非功能需求是否包含可量化的指标？
- [ ] CHK004：是否覆盖了边缘情况（如网络中断、AI服务不可用）？
- [ ] CHK005：是否考虑了财税行业的专业合规要求？

## 5.2 技术方案检查

- [ ] CHK006：技术选型是否与团队能力匹配？
- [ ] CHK007：系统架构图是否清晰展示了各层职责？
- [ ] CHK008：是否考虑了系统的可扩展性？
- [ ] CHK009：是否参考了已有的开源实现？

## 5.3 任务拆解检查

- [ ] CHK010：任务是否按阶段合理拆分？
- [ ] CHK011：每个任务是否有明确的产出？
- [ ] CHK012：任务依赖关系是否清晰？
- [ ] CHK013：工时估算是否合理？
