# SalesAI Coach —— 财税行业销售AI陪练系统

本项目是一个基于 **Agentic RAG** 架构的智能销售训练平台，为财税服务行业的销售与客服团队提供沉浸式实战演练环境。

## 🎯 项目背景
基于某财税科技公司的AI业务场景落地需求，聚焦销售培训痛点，通过AI Agent模拟真实客户，实现零风险、可量化的销售实战演练。

## 🛠 技术栈
- **后端**：Python 3.12+ / FastAPI / LangGraph / PostgreSQL / Chroma
- **前端**：React 18 / Next.js 14 / Tailwind CSS
- **部署**：Docker / GitHub Actions
